PV Physics & Derating Formula

The training target is derived from the standard IEC 61724 / PVGIS empirical photovoltaic cell temperature model:

P(t) = P_peak × (G(t) / 1000) × [1 - γ(T_cell - 25°C)] × η_sys T_cell = T_amb + G(t) × ((NOCT - 20) / 800) γ = 0.004 / °C (Silicon Temp Coeff) NOCT = 45 °C (Nominal Operating Cell Temp) η_sys = 0.86 (14% system & inverter losses)

Physical Clamping: Negative predictions clamped to 0.0 kW; Nighttime generation strictly locked to 0.0 kW whenever GHI ≤ 1.0 W/m².

About SolarPredict

AI-Based Solar Photovoltaic Generation & Energy Forecasting Platform.

BCA Minor Project — University Examination Edition

SolarPredict is an artificial intelligence-driven solar photovoltaic forecasting system designed to predict short-term power output (kW) and estimated daily energy (kWh) of solar installations using forecasted meteorological and solar conditions.

Technology Stack & Implementation Libraries

Python 3.12

Core language for data processing, machine learning pipeline, and API backend.

Scikit-Learn

Supervised regression models: Linear Regression, Decision Tree, and Random Forest.

Flask

Lightweight WSGI web server and REST API delivering JSON forecasts.

Pandas & NumPy

High-performance tabular data manipulation and numerical matrix operations.

SQLite 3

Embedded ACID database storing installation sites and prediction history logs.

Chart.js 4

Interactive HTML5 Canvas visualizations with gradients, tooltips, and responsive scaling.

Joblib

Optimized serialization pipeline for saving and loading trained scikit-learn models.

Open-Meteo API

Open-access meteorological forecast and historical ERA5 reanalysis weather data.
